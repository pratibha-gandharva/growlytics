# Growlytics

**Growlytics** is a student growth and internship-preparation platform designed to help college students organize their learning journey, track progress, manage projects, and follow a personalized roadmap.

## Features

-  Student authentication with Firebase
-  Student onboarding and profile setup
-  Personalized progress dashboard
-  Customizable learning roadmap
-  Study and practice tracking
-  Project management and progress tracking
-  Skills visualization and skill tracking
-  AI-powered chat assistance
-  Light and dark theme
-  Firebase Firestore database integration
-  Responsive user interface

## Tech Stack

**Frontend**
- React
- TypeScript
- Vite
- Tailwind CSS

**Backend & Services**
- Firebase Authentication
- Firebase Firestore

**Libraries & Tools**
- React Router
- Recharts
- Lucide React
- Git & GitHub

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/pratibha-gandharva/growlytics.git
cd growlytics
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure Firebase

Create a `.env` file using the provided example:

```bash
cp .env.example .env
```

Add your Firebase configuration values to `.env`.

> Never commit your `.env` file or expose private API credentials.

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local Vite development URL shown in your terminal.

## Project Goal

Growlytics was built as a portfolio project to explore how technology can help students organize their learning, monitor progress, identify skill gaps, and prepare more effectively for internships.
